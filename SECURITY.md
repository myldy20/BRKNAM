# Security policy

BRKNAM is pre-release software and does not yet provide supported production versions.

Please report security-sensitive issues privately to the repository owner through GitHub rather than publishing model files, access tokens, personal paths, or exploitable details in a public issue. Ordinary crashes and malformed-file bugs may be reported publicly after removing private data and copyrighted model contents.

High-risk areas include untrusted `.nam` metadata, audio/IR parsers, preset JSON, archive extraction, OAuth callbacks, and downloaded filenames.
